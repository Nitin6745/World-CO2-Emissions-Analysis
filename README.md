# 🌍 World CO₂ Emissions Analysis

## 1. Project Overview

An interactive **Power BI Dashboard** developed to analyze global CO₂ emissions across countries, regions, and years.

The dashboard provides insights into **CO₂ emissions, regional contribution, country-wise emissions, and long-term emission trends**.

## 2. Objective

- Analyze global CO₂ emission trends
- Compare emissions across countries and regions
- Identify major CO₂ contributors
- Analyze year-wise emission patterns
- Provide interactive data-driven insights

## 3. Tech Stack

- **Power BI** – Dashboard development & visualization
- **Power Query** – Data cleaning & transformation
- **DAX** – Calculated measures and analysis
- **Data Modeling** – Relationships and reporting

## 4. Dashboard Features

- Total CO₂ Emissions
- CO₂ Emissions by Country
- Region-wise Analysis
- Year-wise Emission Trends
- CO₂ Per Capita Analysis
- Interactive World Map
- Country & Region Filters
- Birth Rate Trend Analysis

## 5. Key Insights

- Total CO₂ emissions shown in the dashboard: **890.62M kt**
- North America represents a major regional contribution.
- The United States is the highest-emitting country in the country comparison.
- China, Japan, India, and Russia are among the other major contributors.
- Global CO₂ emissions show an overall increasing trend over the analyzed period.
- CO₂ emissions vary significantly across countries and regions.

## 6. Business Impact

The dashboard helps users:

- Identify major contributors to global emissions
- Compare emissions across regions and countries
- Monitor long-term emission trends
- Understand geographical emission patterns
- Support data-driven environmental analysis

## 7. Skills Demonstrated

**Power BI | DAX | Power Query | Data Modeling | Data Cleaning | Data Visualization | KPI Development | Geographic Analysis | Trend Analysis**
